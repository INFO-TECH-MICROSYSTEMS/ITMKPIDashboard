# INFO TECH MICROSYSTEMS (ITM) - Enterprise Website

An elegant, modern, high-performance website and interactive KPI tools suite for **INFO TECH MICROSYSTEMS**.

---

## 🚀 Key Features & Highlights

- **Branding & Visual Identity:**
  - Integrated ITM cyber-neon branding with both Dark and Light mode support.
  - Interactive theme toggle automatically adjusting logos, color palettes, and glassmorphic panels.
  - High-resolution founder portrait for **Sudarsha Wijenayake** (Founder & Principal Technology Consultant).

- **7 Dedicated Enterprise Service Pages:**
  1. [`/services/software-development`](http://localhost:5173/services/software-development) - **Software Product Development, Enhancement & Maintenance** (Web, N-tier, Cloud SaaS, Mobile, Microservices).
  2. [`/services/software-consulting`](http://localhost:5173/services/software-consulting) - **Project Lifecycle & Architectural Consulting** (Requirements, Architecture, Testing, Support, Governance).
  3. [`/services/workforce-training`](http://localhost:5173/services/workforce-training) - **Workforce & Individual Technical Training** (Full-Stack, SDET/QA Automation, BDD, SRE).
  4. [`/services/quality-assurance`](http://localhost:5173/services/quality-assurance) - **Quality Assurance Strategy & Test Engineering** (Shift-left QA, Playwright, Cypress, Load/Security testing).
  5. [`/services/technical-recruitment`](http://localhost:5173/services/technical-recruitment) - **Technical Staffing & Talent Recruitment** (Vetted Managers, Developers, SDETs, Writers, Support).
  6. [`/services/kpis-and-audits`](http://localhost:5173/services/kpis-and-audits) - **Software KPIs & Process Audit Frameworks** (DORA metrics, code debt scorecards, compliance audits).
  7. [`/services/performance-management`](http://localhost:5173/services/performance-management) - **Personnel Performance Management & Governance** (Competency matrices, 360 reviews, career ladders).

- **Interactive Engineering & KPI Tools Suite (`/tools`):**
  - **DORA & KPI Health Calculator:** Instant evaluation of Deployment Frequency, Lead Time, CFR, MTTR, Test Coverage, and Defect Escape Rate with actionable recommendations.
  - **Interactive QA Strategy & Audit Checklist Matrix:** 24-point audit framework across Architecture, QA, Security, and Governance with exportable reports.
  - **Engineering Team Capacity & Staffing Calculator:** Live modeling of squad sprint velocity and QA-to-Dev staffing ratios.
  - **KPI Reference Glossary:** Formulas, target benchmarks, and business justifications for all enterprise software KPIs.

- **Dedicated Contact Us Page (`/contact`):**

## 🛠️ Technology Stack

- **Framework:** React 19 + TypeScript
- **Styling:** Tailwind CSS v4 + Custom Cyberpunk / Glassmorphism Glow Utilities
- **Icons:** Lucide React
- **Routing:** React Router 7 (Single Page Application with smooth scroll-to-top)
- **Bundler:** Vite 8

---

## 💻 Development & Deployment Commands

```bash
# Install dependencies
npm.cmd install

# Start local development server
npm.cmd run dev

# Build for production
npm.cmd run build

# Preview production build locally
npm.cmd run preview
```
